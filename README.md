# LearnHub-Online-Learning-Platform
# Project Title: Online Learning Platform

**Prompt:**

Create a modern, attractive, and fully responsive Online Course Website using HTML and CSS.

The website should help students discover online courses, learn new skills, explore instructors, and enroll in courses.

### 1. Navigation Bar
- Website logo: LearnHub
- Home
- Courses
- Categories
- Instructors
- Reviews
- Contact
- Login and Sign Up buttons

### 2. Hero Section
- Add a beautiful educational background image.
- Main heading: "Learn New Skills. Build Your Future."
- Description: "Discover high-quality online courses and learn from expert instructors."
- Add a search bar to find courses.
- Add an Explore Courses button.

### 3. Course Categories
Display attractive category cards:
- Web Development
- Python Programming
- Data Science
- Artificial Intelligence
- UI/UX Design
- Digital Marketing

### 4. Popular Courses
Create attractive course cards with images, course names, instructor names, ratings, prices, and enrollment buttons.

Include these courses:
- Complete HTML and CSS for Beginners
- Python Programming from Zero
- Java Programming Masterclass
- Introduction to Artificial Intelligence
- Web Development Bootcamp
- Data Science Fundamentals

### 5. Instructor Profiles
Display instructor profile cards with:
- Instructor photograph
- Name
- Subject expertise
- Years of experience
- Short introduction

### 6. Course Information
Include:
- Course description
- What students will learn
- Course duration
- Beginner or advanced level
- Number of lessons
- Enroll Now button

### 7. Student Reviews
Add student testimonials with:
- Student photographs
- Student names
- Star ratings
- Short feedback about their learning experience

### 8. Enrollment Section
Create an attractive enrollment section with:
- Course selection
- Student name
- Email address
- Enroll Now button

### 9. Footer Section
Include:
- About Us
- Contact Information
- Social Media Links
- Privacy Policy
- Terms and Conditions
- Copyright information

### 10. Design Requirements
- Use HTML5 for website structure.
- Use CSS3 for styling.
- Use attractive colors such as blue, purple, and white.
- Use modern fonts and professional layouts.
- Add hover effects to buttons and course cards.
- Use high-quality educational images.
- Make the website responsive for mobile, tablet, and laptop screens.
- Maintain proper spacing, alignment, and consistent styling.

**Final Goal:** Build a beautiful, professional, user-friendly online learning website that looks like a real educational platform. Keep the HTML and CSS code clean, simple, and beginner-friendly.
